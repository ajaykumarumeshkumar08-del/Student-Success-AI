# 🎓 Student Success AI

### Academic Performance & Improvement Advisor

Student Success AI is a Python-based web application that helps
students review their academic progress using attendance, internal
marks, assignment completion, and daily study hours.

## 🎯 Objective

To help students identify areas for improvement and receive
personalized study suggestions through an interactive dashboard.

## ❗ Problem Statement

Students may find it difficult to track multiple academic indicators
and identify which areas need more attention.

## ✨ Features

- Student details input
- Academic progress score
- Attendance and internal marks tracking
- Interactive performance charts
- Personalized improvement suggestions
- Simple and user-friendly dashboard

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- Plotly

## ⚙️ How It Works

1. Enter student academic details.
2. Click Analyze Student Performance.
3. View the calculated progress score and status.
4. Review the performance chart.
5. Follow the improvement suggestions.

## 🚀 Installation and Execution

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Create and activate a virtual environment.
4. Install the required libraries:

   pip install -r requirements.txt

5. Run the application:

   streamlit run app.py

## 📊 Scoring Method

The demo calculates a weighted score using:

- Attendance: 30%
- Internal marks: 40%
- Assignment completion: 20%
- Study hours: 10%

The score is an illustrative indicator, not a validated prediction
of examination results.

## ⚠️ Limitations

- Recommendations are rule-based, not generated by a trained ML model.
- The current version does not connect to a college database.
- Results depend on the information entered by the user.
- Sample input values are for demonstration only.
